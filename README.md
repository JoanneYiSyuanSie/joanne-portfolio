# Joanne's Journal ｜ Content Strategy & Technical SEO

> 一位具備 2 年以內行銷經驗的行銷人 Joanne，為了真正理解 **Technical SEO、搜尋引擎爬蟲邏輯、Core Web Vitals 與行銷自動化**，親手搭建的成果實作站點。

---

## 🌟 為什麼行銷人要親手建站？ (Why This Project?)

在過去近兩年的行銷實務中，我深刻體會到：**優質的內容策略若缺乏良好的網站底層體質支援，排名與轉換成效將大打折扣。**

為了打破「行銷人只會寫文案、不懂底層爬蟲與代碼」的刻板印象，我親自探究現代 Web 架構，從 0 搭建了這個具備**新粗獷主義（Neo-Brutalism）**風格的高效能靜態站點，親身實踐各項 Technical SEO、資訊架構與行銷自動化流程。

---

## 🎯 實踐成果與核心亮點 (Key Highlights)

- ⚡ **Core Web Vitals 頂級體質**：採用 Astro 靜態生成（SSG），零運行時無用 JS，首字節時間（TTFB）與最大內容繪製（LCP）近乎即時，Google Lighthouse 評分達 95～100 分。
- 📚 **內容分類學（Taxonomy）與主題群集**：建立階層分明的主題支柱（Pillar Pages）與內部連結網絡，強化搜尋引擎對「主題權威度（Topic Authority）」的識別。
- 🤖 **前瞻 AI 搜尋優化（AEO / GEO）**：配置 `llms.txt` 與標準 XML Sitemap，便於 ChatGPT Search、Perplexity 等生成式 AI 精準檢索與引用。
- ⚙️ **實戰行銷自動化架構（MarTech）**：於真實營運版整合 Cloudflare Pages Functions 邊緣運算，實作表單 Webhook 非同步派發（Discord 即時通知 + Notion 自動建檔）與 Zoho 電子報訂閱。

## 🛠️ 技術選型 (Tech Stack)

| 領域 | 技術選型 | 運用目的 |
| :--- | :--- | :--- |
| **框架** | [Astro 6](https://astro.build/) | 純靜態生成（SSG），追求極致 SEO 爬蟲友善度與頂級載入效能 |
| **UI** | [React 19](https://react.dev/) + [Tailwind CSS v4](https://tailwindcss.com/) | 新粗獷主義（Neo-Brutalism）風格與 4 款無閃爍動態主題切換 |
| **內容層** | Markdown + YAML Frontmatter | 規範化 Slug、標籤、Meta Description 與發布日期管理 |
| **託管部署** | GitHub Actions + GitHub Pages | 每次 Git Push 自動觸發雲端建置與全自動部署 |
